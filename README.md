# Logistic-AI 物流智能调度系统

## 项目概述

基于大模型的物流调度与智能决策系统，解决多约束条件下的实时调度与异常响应问题。

## 核心痛点

1. **多约束调度复杂** — 车辆容量、时间窗、路况、优先级等多维约束难以协调
2. **异常响应慢** — 突发事故、订单取消、交通管制需要快速决策
3. **全局优化难** — 传统算法只能局部优化，缺乏全局视角

## 技术架构

```
└──────────────────┬──────────────────────────────────┘
                   │
┌──────────────────▼──────────────────────────────────┐
│                   RAG 增强层                        │
│  - 历史case检索  - 规则知识库  - 经验参考            │
└──────────────────┬──────────────────────────────────┘
                   │
┌──────────────────▼──────────────────────────────────┐
│                   OR-Tools 优化层                   │
│  - VRP求解  - 全局最优调度  - 约束验证              │
└──────────────────┬──────────────────────────────────┘
                   │
┌──────────────────▼──────────────────────────────────┐
│                   数据层                            │

└─────────────────────────────────────────────────────┘
```

## 硬件环境

- **GPU:** RTX 3050 (4GB)
- **RAM:** 32GB
- **部署:** 本地

## 部署架构

| 层级 | 技术选型 | 硬件需求 |
|------|---------|---------|
| LLM推理 | OpenAI/Claude API + Qwen2-7B (4-bit量化) | GPU 4GB / API |
| 求解器 | OR-Tools | CPU |
| 向量数据库 | Milvus / PgVector | 本地 |
| 量化推理 | llama.cpp | GPU 4GB |
